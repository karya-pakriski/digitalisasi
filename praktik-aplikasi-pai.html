PRAKTIK LANGSUNG

Membuat Aplikasi dengan Google Apps Script & Spreadsheet

Ikuti langkah-langkah — cukup copy-paste kode, deploy, dan aplikasi siap digunakan!

Tidak perlu instalasi — semua di browser!

Langkah 1 — Login Google

1

Buka browser dan login ke akun Google (Gmail) yang akan digunakan untuk membuat aplikasi.

🔗 Buka Gmail / Login

Langkah 2 — Buka Spreadsheet & Apps Script

2

Buka Google Spreadsheet baru, lalu masuk ke menu Ekstensi → Apps Script.

📌 Spreadsheet akan menjadi "database" aplikasi kita. Apps Script adalah tempat kita menulis kode.
📊 Buka Spreadsheet Baru

Langkah 3 — Mengenal kode.gs & HTML

3

Di Apps Script, ada dua jenis file:

📄 kode.gs

Kode backend (server-side) yang berinteraksi dengan Spreadsheet. Berisi fungsi seperti doGet() dan simpanHafalan().

🌐 index.html

Kode frontend (tampilan web) yang akan dilihat pengguna. Berisi form input dan tombol untuk menyimpan data.

Contoh Kode — Aplikasi Pencatat Hafalan

📝

Berikut contoh kode aplikasi sederhana untuk mencatat hafalan siswa.

📄 kode.gs (Backend)

// Server-side: simpan data ke Spreadsheet
function doGet() {
  return HtmlService
    .createHtmlOutputFromFile('index');
}

function simpanHafalan(nama, surah, ayat) {
  var sheet = SpreadsheetApp
    .getActiveSpreadsheet()
    .getActiveSheet();
  sheet.appendRow([
    new Date(),
    nama, surah, ayat
  ]);
  return '👏 Hafalan tersimpan!';
}

🌐 index.html (Frontend)

<!-- Tampilan form input hafalan -->
<!DOCTYPE html>
<html>
  <head>
    <base target="_top">
  </head>
  <body>
    <h1>👏 Pencatat Hafalan</h1>
    <input id="nama" placeholder="Nama">
    <input id="surah" placeholder="Surah">
    <input id="ayat" placeholder="Ayat">
    <button onclick="simpan()">💾 Simpan</button>
    <script>
      function simpan() {
        var nama = document.getElementById('nama').value;
        var surah = document.getElementById('surah').value;
        var ayat = document.getElementById('ayat').value;
        google.script.run
          .withSuccessHandler(alert)
          .simpanHafalan(nama, surah, ayat);
      }
    </script>
  </body>
</html>
💡 Fungsi simpanHafalan() mengirim data dari form ke Spreadsheet. Peserta hanya perlu menyesuaikan dengan kebutuhan mereka.

Langkah 4 — Unduh & Copy-Paste Kode

4

Unduh dua file berikut, buka di editor teks, lalu copy-paste ke Apps Script:

📄 Buka kode.gs 🌐 Buka index.html
💡 Di Apps Script, buat dua file: kode.gs (backend) dan index.html (tampilan). Paste kode dari file yang diunduh.

Langkah 5 — Jalankan & Deploy

5
1️⃣
Simpan & Jalankan

Klik Simpan 💾, pilih fungsi doGet → klik Run → izinkan akses.

2️⃣
Deploy sebagai Web App

Klik Deploy → New deployment → pilih Web app → Deploy.

3️⃣
Salin URL & Gunakan!

Salin URL Web App → buka di browser → aplikasi siap dipakai! 🎉

⭐ Tips: Setiap kali mengubah kode, Anda harus Deploy ulang dengan versi baru agar perubahan muncul.

🔗 Memendekkan Link dengan s.id

🔗
